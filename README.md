# قافلة — متجر إلكتروني عربي متكامل

متجر على طريقة أمازون مبني بـ Next.js (App Router) و PostgreSQL عبر Drizzle ORM، بواجهة عربية كاملة من اليمين إلى اليسار.

## ما الذي يتضمنه؟

**واجهة المتجر**

- صفحة رئيسية: بانر متحرك، أقسام، عروض اليوم، الأكثر مبيعاً، وصل حديثاً.
- بحث حي بالاقتراحات يتسامح مع اختلافات الإملاء العربي (أ/ا، ة/ه، ى/ي).
- تصفية حسب القسم والسعر والتقييم والتوصيل السريع والعروض، مع ترتيب وترقيم صفحات.
- صفحة منتج: معرض صور، مزايا ومواصفات، حالة المخزون، تقييمات العملاء مع شارة «مشترٍ موثّق».
- سلة تعمل للزائر وتنتقل تلقائياً إلى الحساب عند تسجيل الدخول.
- إتمام الطلب بالدفع عند الاستلام، مع حجز المخزون داخل معاملة واحدة.
- طلباتي: تتبّع حالة الطلب وإلغاؤه قبل الشحن (يعود المخزون تلقائياً).
- المفضلة، صفحة الحساب، تغيير كلمة المرور، صفحة مساعدة.

**لوحة التحكم** (`/admin`)

- إحصاءات المبيعات والطلبات والمخزون المنخفض.
- إضافة المنتجات وتعديلها وأرشفتها.
- متابعة الطلبات وتغيير حالتها.

## الحسابات الجاهزة

| الدور | البريد | كلمة المرور |
| --- | --- | --- |
| مدير المتجر | `admin@qafila.store` | قيمة `ADMIN_PASSWORD`، أو `admin1234` إن لم تُحدَّد |
| عميل تجريبي | `demo@qafila.store` | `demo1234` |

> غيّر كلمة مرور المدير من «حسابي» فور أول دخول. تختفي الحسابات التجريبية من صفحة تسجيل الدخول تلقائياً بعد تغيير كلمات مرورها.

## متغيرات البيئة

| المتغير | مطلوب؟ | الوصف |
| --- | --- | --- |
| `DATABASE_URL` | نعم | رابط اتصال PostgreSQL |
| `ADMIN_PASSWORD` | يُنصح به | كلمة مرور المدير عند إنشاء قاعدة البيانات لأول مرة |
| `SUPPORT_EMAIL` | لا | بريد خدمة العملاء المعروض في صفحة المساعدة |

## التشغيل محلياً

```bash
npm install
# ضع DATABASE_URL في ملف .env
npm run dev
```

لا حاجة إلى أي خطوة لتهيئة قاعدة البيانات: عند أول طلب ينشئ التطبيق الجداول (إن لم تكن موجودة) ويملأ المتجر ببيانات تجريبية — 8 أقسام و32 منتجاً مع تقييمات وطلبات نموذجية.

## الاستضافة

### 1) Docker Compose (المتجر + قاعدة البيانات على خادمك)

```bash
ADMIN_PASSWORD='كلمة-مرور-قوية' POSTGRES_PASSWORD='كلمة-أخرى' docker compose up -d --build
```

يعمل المتجر على المنفذ 3000. ضع أمامه خادماً عكسياً يوفّر HTTPS (مثل Caddy أو Nginx) واربطه بنطاقك.

### 2) منصات Node.js (مثل Vercel أو Railway أو Render)

1. أنشئ قاعدة بيانات PostgreSQL مُدارة وانسخ رابط الاتصال.
2. اربط المستودع بالمنصة وأضف `DATABASE_URL` و `ADMIN_PASSWORD`.
3. أمر البناء `npm run build` وأمر التشغيل `npm run start`.

## قبل الإطلاق الفعلي

- **الدفع الإلكتروني غير مفعّل.** المتاح حالياً الدفع عند الاستلام فقط؛ خيار البطاقة ظاهر كـ«قريباً» ويحتاج إلى ربط بوابة دفع (مثل مدى/Moyasar أو Stripe).
- **الصور التجريبية** روابط مباشرة من Pexels. ارفع صور منتجاتك على تخزينك الخاص وضع روابطها من لوحة التحكم.
- **المنتجات والتقييمات والطلبات الأولى بيانات نموذجية** — أرشف المنتجات من لوحة التحكم أو أفرغ الجداول قبل الإطلاق.
- **السياسات** (التوصيل المجاني فوق 200 ر.س، رسوم 19 ر.س، الإرجاع خلال 15 يوماً) قيم افتراضية؛ عدّلها في `src/lib/constants.ts` و `src/app/help/page.tsx`.
- لا يوجد إرسال بريد إلكتروني (تأكيد الطلب، استعادة كلمة المرور) بعد.

## بنية المشروع

```
src/
  app/            الصفحات ومسارات الـ API
  components/     مكوّنات الواجهة (admin/ للوحة التحكم)
  db/             مخطط Drizzle والتهيئة الذاتية للجداول
  lib/            المصادقة، السلة، الاستعلامات، البيانات التجريبية
```

المبالغ تُخزَّن بالهللة (أعداد صحيحة) لتفادي أخطاء التقريب، وكلمات المرور تُجزَّأ بـ scrypt، والجلسات تُحفظ في قاعدة البيانات كتجزئة فقط.
